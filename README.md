# Deep Forest Academy

Локальный веб-учебник-тренажёр **Deep Forest Academy** (DFA, est. 2026). Первая программа — «Математика»: школьное ядро, затем высшая математика.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который напечатает Vite (обычно `http://localhost:5173`). Прогресс и имя слушателя хранятся в `localStorage` браузера.

Сборка:

```bash
npm run build
npm run preview
```

## Как устроена программа

1. Регистрация: имя, которое попадёт на диплом.
2. Вкладка **Программы** — сейчас открыта «Математика»; остальные факультеты помечены как будущие.
3. Школьные курсы открываются последовательно (~50 занятий).
4. После закрытия школы параллельно доступны линейная алгебра, математический анализ, дискретная математика, теория чисел и теория вероятностей.
5. Статистика, ОДУ, комплексный анализ, топология, численные методы и оптимизация открываются по пререквизитам.
6. За занятие — оценка **0.0–4.0** (доля верных ответов). В журнал пишется лучшая попытка. GPA — среднее.
7. После всех занятий выдаётся диплом с подписью ректора Vasya Forester.

Материалы уроков опираются на стандартные учебники (Алимов, Мордкович, Атанасян, Фихтенгольц, Ильин–Позняк, Гнеденко, Виноградов, Александров и др.); источники указаны в каждом занятии.
